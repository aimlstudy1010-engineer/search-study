# AI Search Study

This repository allows you to organize and implement concepts from AI search research papers.

## Structure

- **`papers/`**: Contains notes and implementations for each paper you study.
  - Create a new folder for each paper (e.g., `papers/alphago/`).
  - Use `templates/paper_notes_template.md` for notes.
- **`templates/`**: Templates for standardizing your study workflow.
  - `paper_notes_template.md`: Template for summarizing papers.
- **`common/`**: Shared code and utilities reusable across different paper implementations.

## Workflow

1.  **Pick a paper**: Choose a paper to study.
2.  **Create a folder**: Create a new folder in `papers/` named after the paper.
3.  **Take notes**: Copy `templates/paper_notes_template.md` to your new folder and fill it out.
4.  **Implement**: Write code in your paper's folder, using `common/` for shared logic.
